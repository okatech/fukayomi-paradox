# 深読みパラドックス｜FUKAYOMI PARADOX

> テクノロジーを語るのではなく、テクノロジーを通じて人間と社会を深読みするメディア。

ポッドキャスト『深読みパラドックス』公式サイト（静的サイト・ビルド不要）。

## ナラティブ

サイト全体の構成は、企画のロジックをそのまま画面の縦の流れに落としています。

```
HERO      深く読むほど、わからなくなる。
  ↓
MANIFESTO 情報は誰でも取れる／文脈は深読みしないと見えない
          → ニュースではなく「なぜ今そうなったのか」
  ↓
PARADOX   ふつうの解説番組（＝答えで終わる）との対照
          → 深く読むほど分からなくなる。でも、そのほうが面白い。
  ↓
ABOUT     テックは入口。本当のテーマは「人類はなぜそう考えるのか」
          → 扱う領域：AI／IT／日本企業／資本主義／世代論／歴史／エネルギー／人間
  ↓
EPISODES  何が話されたか、だけ知る（要点・話の流れ・キーワード）
  ↓
HOSTS     Thinker（仮説・歴史・構造）× Challenger（現場・実体験・反証）
          + RULE：収録前、Challenger は台本を読まない
  ↓
LINKS     Podcast / YouTube / X / Shopify
```

## デザイン言語

デザイントーンは [Steve* inc.](https://steveinc.jp/) を参照。
大きな余白、和文タイポグラフィ、単色アクセント、記号モチーフ、
ローディング → 導入の二択 → スクロールフェードイン、という体験構造を踏襲しています。

| 要素 | 内容 |
| --- | --- |
| アクセント | `#e5ff00` エレクトリックイエロー |
| ベース | `#f4f2ee` オフホワイト／`#111114` インク |
| 記号 | `◑` — ふたつの解釈が重なる印（Steve* の `＊` に相当するブランドマーク） |
| 書体 | Zen Kaku Gothic New（和文）／ 自作ドットマトリクス（欧文） |
| 導入 | Steve* の「SOUND ON / OFF」に相当する **「深読みモード / そのまま読む」** の二択 |

### 読み方のふたつのモード

装飾の差ではなく、**本文そのものが入れ替わります**。

| | そのまま読む | 深読みで読む |
| --- | --- | --- |
| 想定 | 音声メディアの入口 | 読むこと自体が体験 |
| 文体 | ですます・短文・日常語 | である・複雑構文・概念語 |
| 態度 | 言い換えて届ける | 言い換えず、留保を残す |

HTML 側は `[data-plain]` / `[data-deep]` のペア（25組）、エピソードは
`lead`/`points` と `leadDeep`/`pointsDeep` を持ちます。両方 DOM に残すため、
検索エンジンとスクリーンリーダーには全文が届きます。

選択は `localStorage` に保存され、2回目以降の訪問ではイントロをスキップします。

### 英文タイポグラフィ（自作）

Web フォントも画像も使わず、`assets/js/dot-type.js` の 5×7 ビットマップ（49文字）を
CSS Grid のドットとして描画しています。

```html
<span class="dot" data-dot="PARADOX" data-dot-scale="l"></span>
```

- `data-dot-scale`: `xs` / `s` /（既定）/ `m` / `l` / `xl`。`clamp()` で画面幅に連動
- `is-panel`: 消灯ドットを薄く残す（LEDパネルの質感）
- `is-anim`: 画面に入ると左上から順に点灯
- 色は `currentColor` に追従。`aria-label` に元の文字列が入るため読み上げ可能

## エピソード概要ファインダー

「聴かなくても何が話されたか分かる」を設計の軸にした中心機能です。

- キーワード全文検索（タイトル・要約・要点・話の流れ・タグ・キーワードを横断）
- タグによる絞り込み（複数選択・OR、タグはデータから自動収集）
- アコーディオンに **3行の要点 / 話の流れ / キーワード / 各配信先リンク**

配信前の回は `status: "planned"` として扱われ、表示が自動的に切り替わります。

| | `planned`（企画中） | 未指定（配信済み） |
| --- | --- | --- |
| 番号 | `PLAN.01` ＋「企画中」バッジ | `EP.01` ＋ 日付・尺 |
| 要点の見出し | 3 POINTS ／ 読みにいく仮説 | 3 POINTS ／ この回の要点 |
| 流れの見出し | OUTLINE ／ 話す予定のこと（時刻なし） | CHAPTERS ／ 話の流れ（時刻あり） |
| 並び順 | 昇順（配信済みの後ろ） | 新しい順（先頭） |
| 視聴ボタン | 非表示 | `links` があれば表示 |

## 更新のしかた

### リンク先の差し替え

`assets/js/site.config.js` の `links` にある `url`（現在は `"#"` のプレースホルダ）を
実際の URL に置き換えるだけで、リンクセクションとフッターの両方に反映されます。

### エピソードの追加

`assets/data/episodes.json` に1件追加します。配信済みにするときは `status` を消して
`date` / `duration` / `chapters[].t` / `links` を埋めてください。

```json
{
  "no": 1,
  "date": "2026-09-03",
  "duration": "52:10",
  "title": "FDEを深読みする",
  "lead": "一行の紹介文",
  "tags": ["AI", "歴史"],
  "points": ["要点1", "要点2", "要点3"],
  "chapters": [{ "t": "00:00", "h": "章タイトル" }],
  "keywords": ["FDE"],
  "links": { "podcast": "https://...", "youtube": "https://..." }
}
```

## ローカルで確認する

`fetch` で JSON を読むため、`file://` ではなく簡易サーバー経由で開いてください。

```bash
python -m http.server 8787
# → http://localhost:8787/
```
